# 试题导入与解析

更新日期：2026-10-11。导航栏顶部依次为“导入考纲”和“导入题目”，右侧均有加号，两者均打开网页内弹窗。首页也保留“导入题目”入口。侧栏缩短子目录与父项的间距，章节之间保留较大间隔。

## 使用

1. 默认选择单题截图，也可选择整份试卷。题目必填，MarkScheme 可选；支持拖入 PDF、PNG、JPEG、WebP、剪贴板图片或粘贴文字。
2. PDF 可选择题目/答案页码，跳过封面及空白页。确认接口后识别，随后核对题号、公式和答案配对；表单可直接修改。高级 JSON 编辑需点击“应用数据到核对表单”。
3. 点击开始解析。完成后进入双卡片界面：每道小题一页，左侧显示小题，公共背景折叠；右侧显示对应的“答案、解析、关联知识点”。答案按行显示，得分代码与含义用点线对齐，评分缩写与易错点折叠。DeepSeek 返回的重点词沿用复习卡片的高光样式。使用底部前后按钮、圆点或键盘左右箭头切页；圆点填色代表整题已有解析，外圈代表当前页。每道整题完成后保存，可停止并继续。

小题只按明确的 `(a)`、`(b)(i)` 等编号拆分，保留整题与父级条件，排除答题点线；普通数学括号不拆。解析仍按整题调用一次，由 `parts` 返回各小题结果，缺少任何小题时拒绝覆盖。历史记录无需重新调用接口即可按编号分页；能明确对应的旧答案显示在相应页，未标明归属的内容保留在“旧版整题解析”中。可点击“更新解析与考点”取得完整结构化结果，失败时原解析保留。

有关联考纲时，题目保存在侧栏该考纲的“历史题目”文件夹中。点击文件夹箭头可在导航栏展开或收起记录，点击记录打开解析；不会因展开目录而离开当前卡片。未关联题目使用同样的目录操作，之后可关联考纲并调整具体考点。已匹配知识点可点击跳到复习卡片。

导入弹窗复用原向导的步骤条、表单和按钮风格，上传区支持拖拽、文件选择和粘贴图片。关闭会保留未完成的导入内容；完成解析后再次导入从上传步骤开始。读取文件或请求期间不能直接关闭，识别与解析可用“停止”中断。桌面左右卡片独立滚动，中间分隔条可拖动调宽；支持方向键微调、Shift 加速、双击或 Home 恢复，比例保存于 `S.paperSplit`。每侧保留可读宽度，窗口变窄时自动限制比例。860px 及以下上下排列并隐藏分隔条，底部切题按钮始终可见。同题刷新保留滚动位置，换题从顶部开始。易错点位于关联知识点上方。

原 PDF 文件只留在当前会话。用于题目的页面会渲染为 JPEG，单独保存在本机 IndexedDB（`revstudio-originals`），不放入 localStorage 或 JSON 备份。左卡默认显示缩略图，“查看原题”打开可滚动的放大窗口，支持 Escape 关闭。刷新后在同一浏览器与网址可继续预览；旧记录、纯文本导入或跨设备恢复没有图片，可用“补充原题”附截图或原题 PDF。删除历史记录同步删除对应图片。图片保存失败会提示，本次会话仍可查看。图形题解析优先附保存的原图，缺图时要求补充，不猜测。

侧栏历史记录右侧的“···”菜单提供导出和删除，打开菜单不会切换题目。删除需确认，正在读取或解析时禁止删除。导出解析使用 `revstudio-paper` JSON，可通过现有导入功能恢复。“备份全部”升级为 v3，包含试题记录，不含 API Key，兼容原 v2 科目备份。

左卡底部放置原题预览和查看按钮，右卡底部折叠原评分标准。阅读页不再显示“解析状态”或导出按钮；更新失败仍在对应卡片显示原因。DeepSeek 在同次解析中生成题目标题，默认文件名及截图名替换为相关概念，用户填写的自定义标题保留；旧截图记录按已有解析标题或本地题干生成显示标题，不自动发请求。

## 模型与请求

DeepSeek 官方当前 `deepseek-flash` 支持图片，Pro 不支持。自定义/本地模型需自行具备图片能力。官方依据：

- https://api-docs.deepseek.com/guides/vision
- https://api-docs.deepseek.com/quick_start/pricing

图片压缩最长边 1600 像素，保留公式与图形；PDF 在浏览器逐页渲染，不把乱码文本层当成可靠题干。每批最多两页，超限或截断拆为单页。识别关闭思考，当前会话缓存成功批次，停止或失败后重试复用这些结果。

识别与解析使用不同提示词：前者只转录并标记不清内容，后者讲解方法与得分依据。文档里的指令只当作考试资料，不作为系统指令。MarkScheme 的 M/A/B/oe 等保留原文，文档自己的定义优先；没有评分标准时标注独立推导，不捏造官方分值。

解析发送当前整题、小题编号与条件、对应评分标准、学生疑问及文档缩写。若关联考纲，每次解析发送该考纲 `items` 中全部已识别小知识点的 ID 和完整原文，不按词筛选、不截断条目，也不发送生成的复习笔记或卡片。提示词要求逐小题遍历整份列表，按所考技能匹配最具体的考点，避免公共背景词干扰；返回链接仍验证实际 ID。整份目录会增加输入用量，不增加额外匹配请求。普通题输出上限 4500 tokens，多小题按每小题约 900 tokens 适度增加，最高 12000；思考模式最高 12000。

每个小题独立返回英文答案行、得分代码、中文解析、重点词和知识点。中文答案返回时拒绝覆盖并显示原因。旧中文答案保留，可点击“更新解析与考点”，更新需要一次模型请求。得分代码只接受评分标准中实际出现且有定义的代码，未附评分标准时清除分数。知识点链接逐小题验证实际 ID；缺链接时仅对分数及领先幅度足够的本地候选补关联，不强行匹配。旧记录可按相同规则补显示链接，用户手动选择或取消的对应关系会持久保存并优先保留。

公式提示词覆盖答案、步骤、原因、评分条件、知识点理由和易错点，要求用数学定界符，禁止加粗或高光 LaTeX 命令。试题专用 `paperMathText` / `paperMd` 在显示层兼容旧版未包裹的完整 TeX 片段及被加粗的原始公式，保留已有定界公式与代码，不改存储原文，不改变普通复习卡片渲染。无法确定边界或花括号不完整时保留原文。仍由 KaTeX 排版，CDN 不可用时保留可读原始公式。

高光提示词要求少量具体概念、关键方法或必要条件，允许空数组；禁止公式、变量、最终值及“方程、积分、代入”等泛词。前端过滤数学片段和泛词，模型没有有效高光时才补出已知概念；移除嵌套短词，最多 6 项。仅处理安全 Markdown 文本节点，避开公式和标签，英文词不匹配到其他词内部。

Flash 文档说明每图最多约 1024 输入 tokens。界面输入估算是粗估，不承诺金额；实际调用显示接口返回的 tokens 与既有人民币价格表估算。自定义接口与不同模型可能采用不同图片计价。

## 文件与状态

- `src/js/papers.js`：试题工作区、识别/解析提示词、清洗、请求、历史、关联。
- `src/css/papers.css`：双卡片、导入弹窗、文件夹与移动布局；在原样式之后加载，复用 `panel`、`block`、`navr`、`d`、`stp`、`panes` 和 `btns`。
- `src/markup/app.html`：解析工作区及侧栏入口；`src/markup/wizard.html`：题目和考纲导入弹窗；`library.js`：首页入口与历史目录事件。
- `overlays.js`：公共弹窗面板切换及关闭；`wizard.js`：考纲向导，并区分两种导入的拖拽；`card.js`：根据当前视图分发键盘切换。
- `state.js`：载入时清洗 `S.papers`；保存函数返回成功状态。`transfer.js`：解析导出恢复、v3 备份。
- `api.js`：支持单次配置快照和受控思考输出上限，原考纲请求默认行为保留。

manifest 登记 31 个拼接源码文件：head 1、CSS 7、HTML 3、JS 19、数据 1。新增区块 `12-papers` / `25-papers`；baseline 不含这些功能，恢复工具会拒绝强制恢复，且不写入源码。
