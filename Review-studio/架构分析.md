本文的合并数量、字节不变记录是整理阶段的历史。随后新增试题工作区，当前为 31 个源码（7 CSS、19 JS）；细节和验证见 `试题功能说明.md`，新 HTML 已不与旧 baseline 相同。

## 目标与运行方式

将 IGCSE 考纲转为保留原文、突出关键词、提供笔记和图示的复习卡片，记录复习进度。内置 Computer Science 的 10 个主题、24 个章节、102 个考点用于复习及 PBL 演示。

原生 JS 单页应用，Python 按清单拼成单 HTML。serve.py 使用标准库提供页面、代理模型请求与磁盘缓存，没有服务端业务数据库或本地模型运行环境。

浏览器读取考纲 → 本地解析或 AI 定位正文 → 重叠窗口提取 → 合并去重 → 模型统计、原文编号、提取结果核对 → 补读 → 用户确认 → 分批生成 → 渲染及 localStorage 保存。

生成支持停止、重试、拆批、保存已完成结果；AI 返回结构化图示描述，由预设渲染器绘制，未调用图像生成。PDF.js 不做 OCR；KaTeX 按需加载。AI 推断补全的考点仍保留标注。

## 仍存在的结构限制

| 事实 | 原因与影响 | 后续建议及代价 |
|---|---|---|
| JS 共享全局状态和函数 | 拼接没有作用域边界，依赖隐含 | 长期扩展时采用命名空间或模块打包；需要验证跨文件调用 |
| 业务流程直接操作 DOM | 识别/生成与 UI 耦合 | 参数、结果、进度回调分离；需验证取消、重试、续传 |
| 响应式之后仍有业务样式 | 原 CSS 层叠顺序 | 针对选择器修复；需手机视觉测试，不能只移动文件 |
| 内置/生成资料两条渲染路径 | 手写 HTML/SVG 与结构化图示并存 | 统一内容模型需要资料迁移，代价较高 |
| localStorage 保存全部科目 | 容量与序列化成本有限 | 有实测瓶颈再考虑 IndexedDB，需数据迁移 |

以上是保留的架构事实，不代表已复现运行故障。本次只整理文件，不顺手修改范围外逻辑。
